# Bonoware / PROBE

원본 PROBE의 컴포넌트·스타일·화면 구성을 유지하면서 빌드와 로컬 백엔드 모킹을 정리한 버전입니다.

## 실행

Node.js 24와 npm을 사용합니다.

```sh
nvm use
npm ci
npm run dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)에 접속합니다. 기존 **Login** 창에는 데모 계정 정보가 입력되어 있어 **로그인**을 누르면 체험할 수 있습니다. 모바일에서는 메뉴의 **로그인/회원가입**을 사용합니다.

- 이메일: `demo@probe.local`
- 비밀번호: `Probe1234!`

## 유지한 화면과 동작

원래 로고, 검정·흰색 헤더, 메인 배너, 상품 카드, 브랜드·가격·사이즈 사이드바, 상품 상세 차트, 로그인 모달, 가입 마법사, 발매 일정, 소식, 구매 단계와 프로필 화면을 사용합니다. 원본의 로고와 배너를 유지하고 작은 화면에서 상품 카드와 프로필 항목이 겹치지 않도록 글자 크기와 간격을 조정했습니다. 복구할 수 없는 외부 API 이미지 대신 저장소에 있던 이미지를 사용합니다.

별도 AWS 계정이나 실제 서버 없이 상품 검색·가격 필터, 로그인·가입, 관심 상품, 댓글, 모의 주문과 취소, 판매 등록과 취소를 체험할 수 있습니다. 기존에 미완성이었던 판매 입력에는 같은 스타일의 가격 입력을 연결했습니다. 구매창의 결제 동작은 모의 주문으로 처리합니다.

계정·관심 목록·댓글·주문·매물은 로컬 Node API 서버의 `.probe/state.json`에 저장합니다. 브라우저별 로그인은 HTTP-only 쿠키로 구분하고, 상품·매물·재고는 같은 서버를 사용하는 접속자끼리 공유합니다. 이전 브라우저 저장소는 삭제하지 않으며 서버로 자동 이관하지 않습니다. StockX 자료를 추가한 상품은 상세에서 품번과 발매 정보를 확인할 수 있습니다. 원화 거래가·재고·거래 내역과 예정 발매 일정은 가상이며 실제 결제·검수·배송·정산·이메일·NFC 인증은 실행하지 않습니다. 데모에는 실제 개인정보와 비밀번호를 입력하지 마세요.

판매 상품은 1,516종입니다. StockX 기반 공개 자료에서 품번으로 중복을 확인했습니다. 자료에 발매일이 없는 상품은 상세 화면에 대시(—)로 표시합니다. 새 상품 이미지는 StockX 이미지 서버에서 불러옵니다. 자세한 자료와 사진 출처는 푸터의 LICENSES에서 확인할 수 있습니다.

## 빌드·검증

```sh
npm run check
npx playwright install chromium webkit firefox
npm run test:e2e
npm run format:check
```

브라우저 테스트는 `npm run build`로 생성한 결과물을 확인합니다. 테스트용 preview 서버는 자동으로 실행됩니다.

```sh
npm run build
npm run preview
```

화면 결과물은 `dist/`, API 서버는 `server-build/`입니다. 두 결과물과 Node 실행 환경이 필요합니다. 미리보기 주소는 [http://127.0.0.1:4173](http://127.0.0.1:4173)입니다. 모킹은 빌드 후에도 Node 서버에서 동작하며 브라우저 서비스 워커에 의존하지 않습니다. `npm run dev`는 API와 Vite를 함께 시작합니다. API 서버가 4173에서 실행 중이면 재사용합니다.

```sh
VITE_BASE_PATH=/Bonoware/ npm run build
```

하위 경로 배포 시 이 설정을 사용합니다. 기존 해시 라우터를 유지하므로 서버의 SPA 경로 재작성은 필요하지 않습니다.

## 구조와 호환성

- `src/components`, `src/views`, `src/assets`, `src/store`: 원본 화면·스타일·Redux 코드.
- `src/classic`: 기존 화면을 Vite에서 실행하는 진입점, API 응답 변환, 로컬 AWS 호환 계층.
- `src/app`: 타입, API 클라이언트, 공통 HTTP 핸들러와 데이터 모델.
- `server`: Node HTTP 서버, 세션 격리·파일 저장·정적 파일 제공·이전 빌드 자산 보관.
- `legacy`: 원본 CRA 진입점·Webpack 설정·스크립트의 참고 사본.
- `ETC`: 원래 Lambda 소스·아카이브. 현재 빌드와 분리되어 있습니다.

Vite 8·TypeScript 7·Node 24를 사용합니다. 기존 Material UI 3 디자인을 그대로 실행하기 위해 React 18.3.1과 React Router 5를 사용합니다. 구형 UI 패키지의 peer 범위는 `.npmrc`의 `legacy-peer-deps`로 처리하고 실제 동작은 브라우저 테스트로 검사합니다. 모든 UI 의존성을 최신 메이저로 교체한 버전은 아닙니다.

Webpack·node-sass 및 실제 AWS·결제 SDK는 현재 설치와 실행에서 제외했습니다. `node_modules`와 빌드 결과물은 Git 추적에서 제거했고, 과거 Git 이력은 수정하지 않았습니다. 원본 소스의 대용량 폰트와 미사용 이미지는 보존하지만 현재 번들에 포함하지 않습니다.

실제 서버로 전환하는 설정과 응답 계약은 [API 문서](docs/API.md), 검증 결과와 남아 있는 의존성 경고는 [현대화 기록](docs/MODERNIZATION.md)을 참고하세요.
