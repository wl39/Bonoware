# 원본 화면 유지와 빌드 현대화

기준일: 2026-11-18. 원본 커밋: `fd2205bf`. 작업 브랜치: `codex/modernize-local-demo`.

## 현재 구현

원본 `src/components`, `src/views`, `src/assets`, `src/store`를 현재 앱으로 사용합니다. CSS·SCSS·JSS·로고·이미지는 원본을 유지합니다. `git diff fd2205bf -- src/assets`에 변경이 없습니다. 배경과 배너 데이터는 기존 저장소 이미지를 사용하며, 외부 StockX 주소로만 지정되어 있던 브랜드 썸네일도 저장소의 이미지로 연결했습니다.

React 18.3.1, Material UI 3.9.4, React Router 5.3.4를 사용해 기존 UI와 호환성을 유지합니다. 빌드는 Vite 8.3.8, 타입 검사 도구는 TypeScript 7.0.2, 모킹은 MSW 3.0.6, 실행 환경은 Node 24입니다. 원본의 Webpack 3·Babel 6·node-sass 도구는 설치하지 않습니다.

`src/classic/main.jsx`가 기존 Redux 스토어와 화면을 시작합니다. `src/classic/handlers.js`가 원본 API 응답 구조를 영속 저장소 및 검증된 `/api` 핸들러에 연결합니다. 브라우저 서비스 워커 대신 Node HTTP 서버에서 MSW의 공통 핸들러를 호출합니다. 계정 비밀번호에는 PBKDF2-SHA256과 계정별 salt를 사용하고, 세션은 HTTP-only 쿠키로 격리합니다. 데이터 파일은 `.probe/state.json`에 원자적으로 교체 저장합니다. 이 파일 기반 데모는 단일 Node 프로세스를 전제로 하며 운영 서비스용 인증·DB는 아닙니다.

## 기능과 호환 수정

- 기존 메인·검색·상품 목록·상세·발매·뉴스·로그인·프로필·구매·판매 화면을 연결했습니다.
- 가격 히스토그램 모킹의 단위 오류를 수정했습니다. 금액을 배열 인덱스로 사용해 수백만 개의 DOM을 생성하던 멈춤을 재현했고, 50개 가격 구간과 최대 50개 그래프 칸으로 제한했습니다.
- 이전 탭의 지연 로딩 파일이 빌드 교체 후 사라지지 않도록 `.probe/asset-cache`에 이전 자산을 보관합니다. HTML은 캐시하지 않으며 지연 로딩 실패 시 재시도합니다.
- 화면 오류 경계, 상품 조회 취소·실패 처리, API 요청 시간 제한을 추가했습니다.
- 로그인 모달 중복 표시, 페이지 이동 후 모바일 메뉴 잔류, 최신 브라우저의 스크롤 반환값과 React effect 정리 함수 충돌을 수정했습니다.
- 티커 애니메이션을 동일한 변형·시간의 JSS keyframes로 처리합니다.
- 구매·회원가입·프로필 주소에서 끊어진 외부 우편번호 스크립트를 제거했습니다. 구매창에서 외부 결제 스크립트를 불러오지 않습니다. 기존 주소 검색 버튼은 가상 주소를 입력하고, 주문 버튼은 로컬 재고를 차감합니다.
- 기존 판매 화면에 같은 스타일의 가격 입력과 등록 동작을 연결했습니다.
- 주문 상세의 버튼으로 모의 주문을 취소하고, 판매 내역에서 등록을 취소할 수 있습니다.
- `node-fetch`의 오래된 전이 의존성은 2.7 계열로 고정해 알려진 헤더 전달 문제를 피했습니다.
- Git의 vendored dependencies 85,203개 파일과 CRA 생성물을 제거했습니다. 과거 이력과 원본 자료는 보존합니다.

## 검증

API 테스트는 인증·계정 격리·댓글·관심 목록·입력 검증·가격 산출·동시 구매·재고 복원·저장소 복구를 검사합니다. 브라우저 테스트는 원본 화면에서 검색·로그인 유지·뉴스·발매 일정·주문·판매·취소·정렬·사이즈 필터·홈 복귀·없는 상품 처리를 확인합니다. 데스크톱·모바일 Chromium, 데스크톱·iPhone 크기의 WebKit, Firefox의 5개 설정에서 총 35개이며 서비스 워커를 차단한 상태로 실행합니다. WebKit 검증은 실제 iPhone 기기 테스트와는 구분됩니다. HTTP 서버 테스트는 쿠키 세션 격리·동시 구매·프로세스 재시작 후 주문 유지·이전 청크 제공을 검사합니다.

Vite 번들 생성은 이 환경에서 약 0.3~0.7초였으며, 타입 검사 시간은 별도입니다. 화면 결과물은 원본 배너·사진을 포함해 약 10MB이며 Node API 서버 결과물이 별도로 필요합니다. 이전 리디자인 결과물의 크기나 테스트 결과와 혼용하지 않습니다. 과거 Webpack 빌드는 재측정하지 않았으므로 개선 배율을 제시하지 않습니다.
